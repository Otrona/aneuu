# 이 책을 펴며

## 다시 리눅스란

**다시**(영어 이름 **Aneuu**)는 서랍 속에 잠든 옛날 노트북을 다시 쓸 수 있게 해 주는
작은 리눅스입니다. 이름처럼, 버려질 뻔한 노트북을 다시 꺼내 쓰자는 뜻입니다.
이 책에서는 헷갈리지 않도록 **다시 리눅스**라고 부릅니다.

윈도우처럼 창과 아이콘이 있는 그래픽 화면 대신, 검은 바탕에 글자로 된
**콘솔(글자 화면)**에서 씁니다. 그래서 메모리가 적고 느린 노트북에서도 빠릅니다.
글자 화면이지만 할 수 있는 일은 많습니다.

| 하고 싶은 일 | 쓰는 프로그램 |
|---|---|
| 문서 쓰기 | WordGrinder (`wg`) |
| 메모, 텍스트 편집 | nano |
| 파일 정리, USB 복사 | nnn, `husb` |
| PDF, 전자책(EPUB), 워드, 한글 파일 보기 | `hv` (han-view) |
| 웹 보기 | w3m, chawan, NetSurf(그림 보임) |
| 메일 | aerc |
| 일정, 할 일 | calcurse |
| 가계부, 표 계산 | sc-im |
| 음악, 동영상, 사진 | cmus, mpv, fbi |
| 유튜브 | `yt` |
| 블루투스 헤드폰, 스피커, 키보드, 마우스 | `hbt` (F8) |
| 번역 | trans |
| 뉴스 구독 | newsboat |
| 팟캐스트 | pod |
| 채팅(IRC) | irssi |
| 내려받기, 토렌트 | aria2, rtorrent |
| 옛날 도스 게임 | DOSBox (`hdos`) |
| 모든 웹사이트(유튜브, 은행) | Firefox (`hx firefox`, 메모리 2 GB 이상) |

모든 곳에서 **한글을 읽고 쓸 수 있습니다.**

## 누구를 위한 책인가

리눅스를 처음 만지는 분을 위한 책입니다. 명령어를 몰라도 됩니다.
이 책에 나오는 대로 **한 글자씩 따라 입력**하면 됩니다.

이 책에서 이렇게 생긴 글자는 키보드로 입력하는 것입니다.

```
desk
```

입력한 뒤에는 늘 **Enter** 키를 누릅니다. 따로 말하지 않아도 그렇습니다.

`F1`, `Ctrl+S` 같은 것은 키를 누르라는 뜻입니다. `Ctrl+S` 는
Ctrl 키를 누른 채로 S 를 누르는 것입니다.

## 길을 잃었을 때

다시 리눅스 안에도 이 책의 요약이 들어 있습니다.

- `doc` — 안내서 (주제를 고르면 그 설명이 나옵니다)
- `F12` — 지금 쓰고 있는 프로그램의 키 요약 (화면 오른쪽에 나왔다가, 다시 누르면 사라집니다)

> **이 판에 대해**: 이 책은 다시 리눅스 **0판**(첫 판)에 맞춰 썼습니다. 지금 판 번호는 `cat /etc/aneuu-release` 로 볼 수 있습니다. 다시 리눅스는 아직 여러
> 노트북에서 시험하는 중이라, 어떤 노트북에서는 이 책과 조금 다르게 움직일 수
> 있습니다. 그럴 때는 [문제 해결](#문제-해결) 장을 보세요.

# 준비하기

## 필요한 것

1. **다시 쓸 노트북** — 2005년 무렵 이후의 것이면 대부분 됩니다.
2. **USB 메모리 하나** — 2 GB 이상. 안의 내용은 지워질 수 있으니 비워 두세요.
3. **USB 를 만들 다른 컴퓨터** — 윈도우, 맥, 리눅스 무엇이든 됩니다.
4. **다시 리눅스 ISO 파일** — 다시 리눅스 설치 파일입니다. 64비트와 32비트 두 가지가 있습니다.

## 64비트와 32비트 고르기

ISO 파일은 두 가지입니다.

- `aneuu-0-x86_64.iso` — 64비트
- `aneuu-0-x86.iso` — 32비트

(가운데 `0` 은 판 번호입니다. 새 판이 나오면 숫자가 커집니다.)

| 노트북 | 고를 것 |
|---|---|
| 2008년 이후 대부분 (코어2 듀오, 코어 i3/i5/i7, AMD 애슬론64 이후) | **64비트** |
| 윈도우 7/10 64비트가 깔려 있던 노트북 | **64비트** |
| 넷북 (아톰 N270, N280), 펜티엄 M, 셀러론 M, 코어 듀오(코어**2** 아님) | **32비트** |
| 잘 모르겠다 | 64비트로 먼저 해 보고, 켜지지 않으면 32비트 |

64비트를 32비트 노트북에서 켜면 "x86-64 CPU 가 필요하다"는 영어 글이 나오고 멈춥니다.
고장이 아니니 걱정하지 말고 32비트로 다시 만드세요.

## 메모리(RAM)는 얼마나

다시 리눅스는 메모리가 **2 GB 이상** 있어야 합니다.

| 메모리 | 할 수 있는 것 |
|---|---|
| 2 GB | USB 로 켜서 바로 모든 콘솔 프로그램과 유튜브를 쓸 수 있습니다 |
| 4 GB 이상 | Firefox 까지 편하게 쓸 수 있습니다 |

노트북의 메모리 크기는 다시 리눅스를 켠 뒤 `free -m` 으로 볼 수 있습니다.

# 부팅 USB 만들기

ISO 파일은 그냥 USB 에 복사만 해서는 켜지지 않습니다. 아래 셋 가운데 하나로 만드세요.

## 방법 1: Ventoy (추천)

Ventoy 를 한 번 설치해 두면, 그다음부터는 ISO 파일을 USB 에 **복사만** 하면 됩니다.
다른 ISO 도 여러 개 넣어 두고 골라서 켤 수 있습니다.

1. 다른 컴퓨터에서 ventoy.net 에 들어가 Ventoy 를 내려받습니다.
2. 압축을 풀고 `Ventoy2Disk.exe` 를 실행합니다.
3. 장치에서 **USB 메모리**를 고르고 **설치(Install)** 를 누릅니다.
   (USB 안의 내용이 모두 지워집니다.)
4. 끝나면 USB 가 `Ventoy` 라는 이름으로 보입니다.
   다시 리눅스 ISO 파일을 그 안에 복사합니다.

켤 때 Ventoy 메뉴가 나오면 다시 리눅스 ISO 를 고르고 Enter 를 누릅니다.
"Boot in normal mode" 를 물으면 그것을 고릅니다.

## 방법 2: Rufus (윈도우)

1. rufus.ie 에서 Rufus 를 내려받아 실행합니다.
2. 장치에서 USB 메모리를, 부트 선택에서 다시 리눅스 ISO 파일을 고릅니다.
3. **시작**을 누릅니다.
4. 쓰기 방식을 물으면 **DD 이미지 모드**를 고릅니다.

## 방법 3: 리눅스나 맥에서

USB 장치 이름을 정확히 확인한 뒤(잘못 고르면 그 디스크가 지워집니다):

```
sudo dd if=aneuu-0-x86_64.iso of=/dev/sdX bs=4M status=progress
sync
```

`/dev/sdX` 는 USB 의 이름(예: `/dev/sdb`)으로 바꾸세요.

# USB 로 켜기

## 부트 메뉴 열기

1. 노트북을 끈 상태에서 USB 를 꽂습니다.
2. 전원을 켜자마자 **부트 메뉴 키**를 여러 번 톡톡 누릅니다.
3. 나온 목록에서 USB(이름에 USB, 또는 USB 회사 이름이 보입니다)를 고릅니다.

노트북 회사마다 키가 다릅니다. 흔한 예는 이렇습니다.

| 회사 | 부트 메뉴 | 바이오스(BIOS) 설정 |
|---|---|---|
| 삼성 | F10 | F2 |
| LG | F10 | F2 |
| 레노버 (씽크패드 포함) | F12 | F1 또는 F2 |
| HP | Esc 다음 F9 | Esc 다음 F10 |
| 델(Dell) | F12 | F2 |
| 에이수스(ASUS) | Esc | F2 |
| 에이서(Acer) | F12 | F2 |
| 도시바 | F12 | F2 |

안 되면 켤 때 화면 아래에 잠깐 나오는 영어 안내("Press F12 for boot menu" 같은)를
보거나, "노트북 모델명 부트 메뉴"로 찾아보세요.

## 시큐어 부트(Secure Boot) 끄기

2012년 이후의 노트북은 "보안 부팅" 때문에 USB 가 켜지지 않을 수 있습니다.
그러면 바이오스 설정에 들어가 **Secure Boot** 를 **Disabled(끔)** 로 바꾸고,
**F10** 으로 저장하고 나옵니다. (메뉴 위치는 보통 Security 나 Boot 안에 있습니다.)

## 켜지는 동안

글자가 빠르게 지나가다가 다음과 같은 줄이 나오면 다 켜진 것입니다.

```
Aneuu 0 (Alpine Linux) tty1
Log in as root.  Then: desk = desktop, doc = guide / 안내서

aneuu login:
```

USB 로 켤 때는 모든 프로그램을 메모리로 옮기기 때문에 1~3분쯤 걸립니다.

# 처음 로그인

## 로그인하기

`login:` 옆에 `root` 를 입력하고 Enter 를 누릅니다.
USB 로 처음 켰을 때는 **비밀번호가 없어서** 바로 들어가집니다.

```
aneuu login: root
```

들어가면 다시 리눅스의 짧은 안내가 나오고, 맨 아래에 이런 줄이 보입니다.

```
aneuu:~#
```

이것을 **프롬프트**라고 합니다. "이제 명령을 입력하세요"라는 뜻입니다.

> **root** 는 이 컴퓨터의 관리자 이름입니다. 다시 리눅스는 한 사람이 쓰는 노트북을
> 위한 것이라 root 로 씁니다.

## 비밀번호 정하기

인터넷에 연결하기 전에, 그리고 하드디스크에 설치할 생각이면 꼭 비밀번호를 정하세요.

```
passwd
```

새 비밀번호를 두 번 묻습니다. 입력하는 동안 화면에 아무것도 나오지 않는데,
고장이 아니라 비밀번호를 숨기는 것입니다. 입력하고 Enter 를 누르면 됩니다.

## 첫 명령 해 보기

```
doc
```

안내서가 열립니다. 처음에는 언어를 묻습니다. `1` (한국어)을 고르세요.
주제 번호나 이름을 입력하면 그 설명이 나오고, `q` 를 누르면 닫힙니다.

# 한글 입력

## 한/영 바꾸기

**오른쪽 Alt** 키(한/영 키가 있으면 그 키도)를 누를 때마다 한글과 영어가 바뀝니다.
자판은 **두벌식**입니다. 윈도우에서 쓰던 그대로입니다.

연습해 보세요. 한글 상태에서 `dkssudgktpdy` 를 치면 **안녕하세요**가 됩니다.

## 한글이 되는 곳

| 어디에서 | 한글 입력 |
|---|---|
| `desk` (콘솔 데스크톱) 안의 모든 프로그램 | 오른쪽 Alt |
| `han` (문서 작성), `han -s` (한글 셸) | 오른쪽 Alt |
| NetSurf (그림이 보이는 웹) | 그 안에서 오른쪽 Alt |
| Firefox (`hx firefox`) | 그 안에서 오른쪽 Alt |

로그인한 바로 그 화면(프롬프트)에서는 한글이 **보이기만** 하고 입력은 안 됩니다.
한글을 입력하려면 `desk` 를 먼저 켜세요. 이 책에서는 늘 `desk` 안에서 쓴다고 생각하면 됩니다.

## 글꼴과 글자 크기

처음에는 영어는 Terminus, 한글은 도스 명조(myungjo) 글꼴로 나옵니다(16 픽셀).
로그인한 바로 그 화면(커널 콘솔)도 같은 두 글꼴을 씁니다. 그래서 desk 안과 밖의 글자 모양이 같습니다.
다른 한글 비트맵 글꼴도 여러 가지 들어 있습니다: 도스 시절 글꼴, 갈무리, 네오둥근모 등.

```
han -l
```

크기별 글꼴 목록이 나옵니다. 모양을 직접 보려면(한글 화면 밖, 로그인한 바로 그 화면에서):

```
han -d
```

글꼴을 하나씩 보여 줍니다(Enter 다음, q 그만). 마음에 드는 글꼴로 문서 작성을 시작하려면 이름을 붙입니다.

```
han gothic
han neodgm32
```

화면이 큰 노트북은 24, 32 픽셀 글꼴(`miraero`, `neodgm32`)이, 작은 넷북은 16 픽셀 글꼴이 보기 좋습니다.
글꼴은 han 을 새로 켤 때만 바뀝니다. 이미 한글 화면 안이라면 `exit` 로 나간 뒤 다시 켜세요.

영어 글자를 명조와 어울리는 **세리프(삐침이 있는) 글꼴**로 바꿀 수도 있습니다:

```
HAN_LATIN="Courier Bitmap" han
```

| 글꼴 | 모양 |
|---|---|
| `Courier Bitmap` | 비트맵 쿠리어 (9x15). 16 픽셀 한글 글꼴과 잘 맞고 글자 사이가 촘촘합니다 |
| `Courier Prime` | 깔끔한 쿠리어. 글자 칸이 넓어 사이가 조금 뜹니다 |
| `Libertinus Mono` | 책 글꼴 느낌. 큰 글꼴(24 픽셀 이상)에 좋습니다 |
| `IBM Plex Mono` | 획이 굵어 작은 글씨도 잘 보입니다 |

늘 그렇게 쓰려면 `/etc/han.conf` 에 `LATIN="Courier Bitmap"` 를 적습니다 (root).
(한글이 보이는 커널 콘솔에서는 `han -f` 로 켜야 이 글꼴이 쓰입니다. 커널 콘솔의 글꼴은 도스 명조와 Terminus 로 정해져 있습니다.)

# 콘솔 데스크톱: desk

## 데스크톱 열기

```
desk
```

화면 아래에 파란 **상태 줄**이 생깁니다. 왼쪽에는 열려 있는 창의 목록,
오른쪽에는 배터리, 네트워크, 남은 메모리, 날짜와 시각이 보입니다.

데스크톱에서는 프로그램 하나가 **창** 하나를 차지합니다. 창은 겹치지 않고,
책장을 넘기듯 하나씩 바꿔 봅니다.

## 꼭 알아 둘 키

| 키 | 하는 일 |
|---|---|
| `F1` | 프로그램 메뉴 |
| `F2` / `F3` | 이전 창 / 다음 창 |
| `F4` | 새 셸 창 (명령을 입력하는 창) |
| `F5` | 무선랜 목록 |
| `F6` | 화면 글 복사 시작 |
| `F7` | 복사한 글 붙여넣기 |
| `F8` | 블루투스 기기 |
| `F11` | 일하면서 옆에 책 펴기 (다시 누르면 닫힘) |
| `F10` / `F9` | 책 다음 쪽 / 앞 쪽 |
| `F12` | 지금 프로그램의 키 요약 (다시 누르면 닫힘) |
| `Alt+G` | AI 에게 묻기 (다시 누르면 닫힘) |
| `Alt+O` | 옆 칸으로 (쓰던 글과 AI 칸, 책 사이) |
| `Alt+D` | 영어 단어 뜻 (단어 앞 글자 입력, `Tab` 다음, `Enter`) |
| `Alt+N` | 뉴스 피드 보기 / 숨기기 (오른쪽 패널) |
| `Alt+P` | 팟캐스트 재생기 보기 / 숨기기 |
| `Alt+V` | 재생 중인 영상으로 (영상에서 `Tab` 은 데스크톱으로) |
| `Alt+W` | (w3m 에서) 보고 있는 페이지의 글을 WordGrinder 로 |
| 오른쪽 Alt | 한글 / 영어 |

## 프로그램 메뉴 (F1)

`F1` 을 누르면 화면 가운데에 메뉴가 나옵니다. 화살표로 고르고 Enter,
또는 오른쪽 괄호 안의 글자 키를 바로 누릅니다. `>` 가 붙은 줄은 하위 메뉴이고,
하위 메뉴에서 `,` (쉼표) 를 누르면 처음 메뉴로 돌아갑니다. `F1` 을 한 번 더 누르거나 `Esc` 를 누르면 메뉴가 닫힙니다.

| 처음 메뉴 | 키 | 안에 있는 것 |
|---|---|---|
| 글쓰기 Write | w | 문서 작성 (WordGrinder) |
| 편집 Edit text | e | 텍스트 편집 (nano) |
| 파일 Files | f | 파일 관리 (nnn) |
| 인터넷 Internet > | i | 웹 (w3m, chawan, NetSurf), 메일, 뉴스, 팟캐스트, 채팅, 유튜브, 토렌트, Firefox |
| 생활 Daily > | d | 일정, 표 계산, 주소록, 음악 |
| 놀이 Fun > | p | 도스 게임, 어드벤처 게임, NetHack |
| 시스템 System > | s | 무선랜, 블루투스, USB 연결, 시스템 보기, 디스크 사용량, 화면 잠금 |
| 새 셸 Shell | t | 명령을 입력하는 새 창 |
| 안내서 Guide | ? | doc |
| 끝내기 Quit | q | 데스크톱 끝내기 |

프로그램을 끝내면 그 창도 닫힙니다.

## 화면의 글 복사하고 붙여넣기 (F6, F7)

콘솔에서는 마우스를 쓸 수 없어서, 키보드로 글을 고릅니다.

1. `F6` 을 누릅니다. 화면 오른쪽 위에 `[0/120]` 같은 표시가 나오면 복사 상태입니다.
2. 화살표로 복사할 글의 **처음**으로 갑니다. `Space` 를 누릅니다.
3. 화살표로 글의 **끝**으로 갑니다. 고른 부분이 색으로 보입니다.
4. `Enter` 를 누르면 복사되고 복사 상태가 끝납니다. (그만두려면 `q`)
5. 붙여넣을 곳으로 가서 `F7` 을 누릅니다.

예전에 지나간 글을 보고 싶을 때도 `F6` 을 누르고 `PgUp` 으로 올라가 보면 됩니다.

## 키 도움말 (F12)

어떤 프로그램에서든 `F12` 를 누르면 화면 오른쪽 3분의 1에 그 프로그램의 키 요약이
나옵니다. 보면서 일하다가 `F12` 를 다시 누르면 사라집니다.

## 일하면서 옆에 책 펴기 (F11)

`F11` 을 누르면 화면 오른쪽에 책이 펴지고, 위에 책 이름이 나옵니다. 키보드는 그대로 왼쪽에 있어서,
글을 쓰거나 명령을 입력하거나 웹을 보면서 옆의 책을 함께 볼 수 있습니다.
처음에는 바로 이 설명서가 들어 있습니다.

| 키 | 하는 일 |
|---|---|
| `F11` | 책 펴기 / 닫기 |
| `F10` | 다음 쪽 |
| `F9` | 앞 쪽 |

읽던 곳은 기억합니다. 닫았다가 다시 펴도, 다른 창에서 펴도 그 쪽이 나옵니다.

`F12` 는 다릅니다. `F12` 는 **지금 쓰는 프로그램의 키 요약**을 잠깐 보여 주는 것이고(다시 누르면 닫힘),
`F11` 은 **책이나 긴 글**을 일하는 동안 옆에 계속 펴 두는 것입니다.

다른 책을 넣으려면 `hb` 를 씁니다. EPUB 전자책, PDF, 워드(.docx, .doc), 한글(.hwpx, .hwp), .odt, .rtf, 텍스트, 웹 페이지(.html)의 글을 읽습니다 (PDF 는 글자만, 그림은 빠집니다):

```
hb 소설.epub
```

스캔한 PDF 는 글자 없이 그림만 있어서 `hb` 가 그냥은 읽지 못합니다. 최근 노트북이라면 한 번
`had ocr` (root, 인터넷 필요, 약 40 MB) 를 하면 `hb` 가 쪽마다 글자를 읽어 냅니다(OCR, 쪽마다 몇 초).
오래된 노트북에서는 느리니, 그때는 `hv` 로 쪽 그림을 보세요.

그 책이 화면 가득 열리고(`Space` 다음 쪽, `b` 앞 쪽, `q` 닫기), 그다음부터 `F11` 은 그 책을 보여 줍니다.
nnn 에서 EPUB 파일에 Enter 를 눌러도 같습니다. 다시 이 설명서로 돌아가려면 `hb -r`.

## 데스크톱에서 잠깐 나가기

`Ctrl+b` 를 누르고 손을 뗀 뒤 `d` 를 누르면 데스크톱에서 나옵니다.
열어 둔 프로그램은 그대로 돌고 있으니, `desk` 를 다시 입력하면 그대로 돌아옵니다.
완전히 끝내려면 `F1` 메뉴의 **Quit desktop** 을 고릅니다.

# 블루투스: 헤드폰, 스피커, 키보드, 마우스

데스크톱에서 `F8` 을 누릅니다. (데스크톱 밖이면 `hbt`)

## 새 기기 연결하기

1. 기기를 **연결 대기(페어링)** 상태로 둡니다. 보통 전원 단추나 블루투스 단추를
   몇 초 길게 누르면 불빛이 빠르게 깜박입니다. (기기 설명서를 보세요.)
2. `s` 를 누릅니다. 10초 동안 주변 기기를 찾습니다.
3. 목록에 기기가 나오면 그 번호를 입력합니다.

   ```
   블루투스 기기
      1) 소니 WH-1000XM4        헤드폰
     -- 새로 찾은 기기 --
      2) JBL Flip 5               스피커

   번호 = 연결/끊기,  s = 새 기기 찾기,  x번호 = 지우기 (예: x2),  q = 끝
   > 2
   ```

4. 짝을 맺고(페어링) 연결합니다. `연결됨` 이 나오면 끝입니다.

- **키보드**는 화면에 여섯 자리 숫자가 나옵니다. 그 숫자를 **블루투스 키보드로** 치고 Enter 를 누르세요.
- **휴대폰**이 숫자가 같은지 물으면 `yes` 를 입력합니다.

## 다음부터는

한 번 짝을 맺은 기기는 목록에 늘 남습니다. 다음에는 `F8` 을 누르고 **번호만** 입력하면 연결됩니다.
기기에 따라서는 켜기만 해도 저절로 다시 연결됩니다.

| 입력 | 하는 일 |
|---|---|
| 번호 | 연결, 이미 연결되어 있으면(`*` 표시) 끊기 |
| `x` 번호 (예: `x2`) | 목록에서 지우기 (다시 쓰려면 새로 짝 맺기) |
| `s` | 새 기기 찾기 |
| `q` | 닫기 |

화면 아래 상태 줄에 `bt 기기이름` 이 보이면 연결되어 있는 것입니다.

## 블루투스로 소리 듣기

헤드폰이나 스피커가 연결되어 있는 동안 모든 소리(음악, 동영상, 유튜브, 도스 게임)가 **저절로** 그리로 갑니다.
끊으면 노트북 스피커로 돌아옵니다.

- 연결하기 **전에** 틀어 둔 음악이나 영상은 한 번 끄고 다시 틀어야 블루투스로 나옵니다.
- 소리 크기는 기기의 단추나 `alsamixer` 로 바꿉니다.

## 폰 키보드: hkb

이 노트북을 **폰의 블루투스 키보드**로 쓸 수 있습니다. 폰에서 제미나이 같은 AI 에게 물을 때, 작은 화면 대신 노트북 키보드로 길게 씁니다.

1. root 로 `hkb` (또는 `F1` → **시스템** → **폰 키보드**).
2. 폰의 블루투스 목록에서 **Aneuu keyboard** 를 고릅니다. 처음 한 번만 연결(페어링)하면 됩니다.
3. "연결됨" 이 나오면 노트북의 **모든 키가 폰으로** 갑니다.
4. **명령 키**는 오른쪽 `Ctrl` 입니다 (한국 노트북에서는 흔히 `한자` 키, 둘 다 됩니다). 누른 채로 다른 키를 누릅니다. 이 키는 폰으로 가지 않습니다. 왼쪽 `Ctrl` 은 폰의 `Ctrl` 그대로입니다.
5. `오른쪽 Ctrl+Tab` 을 누르면 키가 **노트북(데스크)** 으로 갑니다. 폰은 연결된 채입니다. 창을 옮기고, `F6` 으로 복사하고, `wg` 에 쓸 수 있습니다. 한 번 더 누르면 다시 폰으로. 바뀔 때마다 아래 상태 줄에 "→ 폰" 이나 "→ 노트북" 이 잠깐 나옵니다.
6. 끝낼 때는 `오른쪽 Ctrl+Q` (폰 쪽에서도, 노트북 쪽에서도).

`Ctrl+Alt` 를 쓰지 않는 까닭: 다른 컴퓨터의 가상 머신(VM)에서 돌리면 그 컴퓨터(Xfce, QEMU)가 `Ctrl+Alt` 키를 먼저 가져갑니다. Xfce 의 `Ctrl+Alt+Esc` 는 창을 죽이는 키입니다.

**복사와 붙여넣기**

- **노트북 → 폰:** `오른쪽 Ctrl+Tab` 으로 노트북에 와서 `F6` 으로 글을 복사하고, `오른쪽 Ctrl+Tab` 으로 폰에 돌아가 `오른쪽 Ctrl+V` 를 누르면 그 글을 폰에 **입력**해 줍니다. 한글도 됩니다 (폰의 한/영을 알아서 바꿉니다). 폰이 따라오도록 **천천히** 칩니다: 300 글자에 30 초쯤. 아래 상태 줄에 얼마나 쳤는지 나오고, `Esc` 로 멈춥니다. 그동안 다른 키는 폰으로 가지 않습니다. 글자가 빠지면 더 천천히: `hkb -d 40` 으로 시작하세요 (숫자가 클수록 느림, 처음은 20). 줄 바꿈은 `Shift+Enter` 로 보냅니다. 챗에서 `Enter` 는 **보내기**라서, 그냥 `Enter` 로 치면 첫 줄만 보내지고 나머지는 사라집니다.
- **폰 → 노트북:** 노트북과 폰이 **같은 와이파이**에 있으면 `hkb` 가 화면에 주소를 보여 줍니다 (예: `http://192.168.0.5:8000/k3f9q`). 폰의 브라우저에서 그 주소를 엽니다. `오른쪽 Ctrl+U` 를 누르면 그 주소를 폰에 입력해 줍니다. 제미나이의 답을 길게 눌러 복사해서 상자에 붙여넣고 **보내기**. `오른쪽 Ctrl+Tab` 으로 노트북에 와서 `F7` 로 붙여넣습니다 (예: `wg` 안에).
- 그 쪽에는 노트북에서 복사한 글도 보입니다. 길게 눌러 폰에서 복사할 수 있습니다.
- 주소 끝의 글자는 그때마다 바뀝니다. 같은 와이파이의 다른 사람이 쉽게 열지 못하게 하려는 것이고, `hkb` 를 끝내면 쪽도 닫힙니다.

**한글은 폰이 만듭니다.** 처음 한 번 폰 설정에서 물리 키보드(실제 키보드, 하드웨어 키보드)를 찾아 **한국어 두벌식**으로 정하세요. 메뉴 이름은 폰마다 조금 다릅니다.

| 폰 | 한/영 바꾸기 |
|---|---|
| 안드로이드 (삼성, Gboard) | 노트북의 오른쪽 `Alt` (폰에는 Shift+Space 로 갑니다) |
| 아이폰 | `Caps Lock` |

`hkb` 를 쓰는 동안은 블루투스가 이 일만 하므로 블루투스 헤드폰이 끊깁니다. 끝내면 다시 연결할 수 있습니다.

## 블루투스가 없다고 나올 때

노트북에 블루투스가 없거나 꺼져 있는 것입니다. 오래된 노트북은 블루투스가 없는 것이 많습니다.
USB 블루투스 동글(몇천 원)을 꽂으면 됩니다. 노트북에 무선 스위치나 `Fn` 키가 있으면 켜 보세요.

# 파일과 USB 메모리

## 폴더와 파일

다시 리눅스에서 내 파일은 **`/root`** 폴더에 둡니다. 이것을 "홈 폴더"라고 하고 `~` 로 줄여 씁니다.
도스 게임은 `~/dos`, 음악은 `~/music` 처럼 폴더를 만들어 두면 편합니다.

```
mkdir ~/문서 ~/music ~/dos
```

## 파일 관리자 nnn

```
nnn
```

| 키 | 하는 일 |
|---|---|
| 화살표 위/아래 | 고르기 |
| Enter 또는 → | 열기 (PDF, 전자책, 사진, 영상... 무엇이든), 폴더 들어가기 |
| ← | 위 폴더로 |
| `/` | 이름으로 거르기 |
| `Space` | 파일 선택 (여러 개 가능) |
| `p` | 선택한 파일을 지금 폴더로 **복사** |
| `v` | 선택한 파일을 지금 폴더로 **이동** |
| `?` | 모든 키 보기 |
| `q` | 끝내기 |

## USB 메모리 쓰기

1. USB 메모리를 꽂고 몇 초 기다립니다.
2. 연결합니다.

   ```
   husb
   ```

   `연결됨: /media/usb` 가 나오면 USB 안이 `/media/usb` 폴더로 열린 것입니다.
3. 파일을 복사합니다. nnn 으로 해도 되고, 명령으로 해도 됩니다.

   ```
   cp ~/문서/편지.odt /media/usb/
   ```

4. **빼기 전에 꼭** 연결을 끊습니다.

   ```
   husb off
   ```

   `이제 뽑아도 됩니다` 가 나온 뒤에 뽑으세요. 그냥 뽑으면 파일이 망가질 수 있습니다.

한글 파일 이름도 그대로 보입니다. 윈도우에서 쓰던 USB(FAT32, exFAT, NTFS)를 모두 읽고 쓸 수 있습니다.

> 다시 리눅스를 켠 그 USB(특히 Ventoy USB)는 켜져 있는 동안 파일 저장용으로 쓰기 어렵습니다.
> 파일은 **다른 USB 메모리**에 담으세요.

# 저장과 설치

## 꼭 알아야 할 것: USB 로 켜면 끄는 순간 잊습니다

USB 로 켠 다시 리눅스는 시스템 전체가 **메모리(RAM)** 위에서 돕니다. 그래서 빠르고,
노트북의 하드디스크를 전혀 건드리지 않습니다. 하지만 끄면 그동안 만든 파일,
무선랜 비밀번호, 바꾼 설정이 **모두 사라집니다.**

그래서 두 가지 쓰는 법이 있습니다.

| 쓰는 법 | 좋은 점 | 할 일 |
|---|---|---|
| USB 로 켜서 쓰기 | 노트북을 건드리지 않음. 시험해 보기 좋음 | 만든 파일은 꼭 다른 USB 에 복사 |
| 하드디스크에 설치 | 모든 것이 남음. 더 빨리 켜짐 | `hinst` 한 번 |

오래 쓸 노트북이면 **설치**를 권합니다.

## 하드디스크에 설치하기: hinst

> **주의**: 고른 디스크의 **모든 것이 지워집니다.** 윈도우도, 사진도, 문서도.
> 남길 파일이 있으면 먼저 다른 곳에 옮겨 두세요.
> 윈도우와 함께 두고 골라 켜는 방식(듀얼 부팅)은 지원하지 않습니다.

1. USB 로 켜서 root 로 로그인하고, `desk` 를 엽니다.
2. 입력합니다.

   ```
   hinst
   ```

3. 디스크 목록이 나옵니다. 크기를 보고 노트북 안의 디스크 번호를 입력합니다.

   ```
   어느 디스크에 설치할까요?
     1)  /dev/sda 111.8G disk sata Samsung SSD
   > 1
   ```

4. 경고가 나오면 `yes` 를 입력합니다. (다른 글자를 입력하면 그만둡니다.)
5. root 비밀번호를 아직 정하지 않았으면 여기서 정합니다.
6. 설치가 진행됩니다. 영어 글이 지나가는 동안 기다립니다.
7. `끝났습니다` 가 나오면:

   ```
   poweroff
   ```

   꺼지면 USB 를 뽑고 다시 켭니다.

설치한 뒤에는 켤 때마다 root 와 정한 비밀번호로 로그인합니다.
USB 로 켰을 때 만든 파일(`/root` 안)과 무선랜, 설정은 함께 옮겨집니다.

## 설치한 뒤 새로 고치기 (업데이트)

한 달에 한 번쯤, 인터넷에 연결한 상태에서:

```
apk update
apk upgrade
```

보안 문제가 고쳐진 새 프로그램을 받습니다. 다시 리눅스만의 한글 커널과 한글 NetSurf 는
바뀌지 않도록 고정되어 있으니 그대로 두어도 됩니다.

## 더 설치하기: had

USB 로 켜면 모든 프로그램이 메모리에 올라갑니다. 그래서 무거운 프로그램은 처음에는 빠져 있고,
필요할 때 **한 번** 설치합니다. 목록을 봅니다 (`F1` → **시스템** → **더 설치하기** 도 같습니다):

```
had
```

| 이름 | 무엇 | 메모리 |
|---|---|---|
| `had netsurf` | 그림이 보이는 웹 브라우저 | 약 250 MB |
| `had dosbox` | 도스 프로그램 실행기 (`hdos`), 게임은 따로 | 약 250 MB |
| `had scummvm` | 옛 어드벤처 게임 실행기, 게임은 따로 | 약 260 MB |
| `had hwdec` | 영상을 그래픽 칩으로 풀기 (빠르고 조용함) | 약 20 MB |
| `had firefox` | Firefox (인터넷 필요) | 2 GB 이상 |
| `had hwp` / `had ocr` | 한글 .hwp 보기 / 스캔한 PDF 읽기 (인터넷 필요) | |
| `had yt` | 유튜브가 안 될 때 yt-dlp 새로 받기 (인터넷 필요) | |

root 로 실행합니다. `netsurf`, `dosbox`, `scummvm`, `hwdec` 는 USB 안에 들어 있어서 인터넷 없이 설치됩니다.
`netsurf`, `dosbox`, `scummvm` 은 그래픽 부분(Mesa, 약 230 MB)을 함께 씁니다.
USB 로 켠 상태에서 설치한 것은 다시 켜면 없어지고, 쓰는 동안 메모리를 차지합니다.
그래서 [하드디스크에 설치](#하드디스크에-설치하기-hinst)한 뒤에 쓰면 좋습니다.
설치되지 않은 프로그램을 켜면 어떻게 설치하는지 알려 줍니다.
다시 빼려면 `hadr 이름` (예: `hadr dosbox`) 입니다. `hadr` 만 치면 설치된 것을 보여 줍니다.
같이 쓰는 그래픽 부분(Mesa)은 그것을 쓰는 프로그램이 모두 빠졌을 때만 함께 빠집니다.

그 밖의 알파인 프로그램은 `apk` 로 받습니다:

```
apk search 이름      (찾기)
apk add 이름         (설치)
```

USB 로 켜서 쓰는 중이라면 먼저 `had net` 을 한 번 입력해야 인터넷에서 받을 수 있습니다.

# 문서와 책 보기: hv

받은 파일을 열어 볼 때는 무엇이든 `hv` 하나로 됩니다 (긴 이름은 `han-view`).

```
hv 보고서.pdf
```

nnn 에서 파일을 고르고 **Enter** 를 눌러도 똑같이 열립니다.

| 파일 | 어떻게 열리나 | 키 |
|---|---|---|
| PDF | 화면 가득, 쪽 그대로 | `Space` 다음 쪽, `b` 앞 쪽 (`PgDn`/`PgUp` 도 됨), `+`/`-` 크기, `q` 끝 |

| 워드 `.docx` `.doc`, 한글 `.hwpx`, `.odt`, `.rtf` | 글만 뽑아서 보기 | 화살표, `q` 끝 |

| 압축 파일 | 안에 든 파일 목록 | `q` 끝 |

워드와 한글 문서는 **글만** 보입니다. 표와 그림은 빠집니다.
고쳐서 보내야 하는 문서는 다른 컴퓨터에서 여는 것이 낫습니다.

`.hwp` 파일을 보려면 인터넷에 연결하고 한 번만:

```
had hwp
```

(`.hwpx` 는 이것 없이도 열립니다.)

# 문서 작성: WordGrinder

```
wg
```

한글 입력이 되는 문서 작성 프로그램 WordGrinder 가 열립니다. 바로 글을 쓰면 됩니다.
데스크톱(`desk`) 안에서도, 밖에서도 `wg` 입니다. 밖에서는 `han` 과 같습니다(한글 화면을 켜고 WordGrinder).

| 키 | 하는 일 |
|---|---|
| `Esc` | 메뉴 (File 파일, Edit 편집, Style 스타일 ...) |
| `Ctrl+S` | 저장 |
| `Ctrl+Q` | 끝내기 |

처음 저장하면 파일 이름을 묻습니다. `편지.wg` 처럼 끝에 `.wg` 를 붙이세요.
저장해 둔 문서를 다시 열 때는 `wg 편지.wg` 입니다.

## 다른 컴퓨터로 보내기

`.wg` 파일은 WordGrinder 만 엽니다. 그래서 `Ctrl+S` 로 저장할 때마다 같은 이름의 `.odt` 파일도
함께 저장됩니다 (`편지.wg` 옆에 `편지.odt`). 다른 사람에게는 `.odt` 를 보내세요.
`.odt` 파일은 LibreOffice, 한컴오피스, MS 워드에서 열립니다.

다른 형식(텍스트, HTML 등)이 필요하면: `Esc` → **File** → **Export** → 형식 고르기.

영어로 쓸 때 `i` 하나만 쓰면 저절로 `I` 가 됩니다 (`i'm` → `I'm`).

## 웹 글을 가져와 쓰기

웹에서 읽은 글을 옮겨 놓고 그 사이사이에 내 생각을 쓰고 싶을 때:

```
wg https://주소
```

메뉴, 광고, 댓글 같은 것은 빼고 본문만 새 문서로 엽니다 (`~/web/` 에 저장).
w3m 으로 보고 있다면 `Alt+W` 한 번이면 같은 일을 합니다. 새 창에 WordGrinder 가 열리고, w3m 은 그대로 있습니다.

페이지를 다시 받아 오므로 몇 초 걸립니다. 자바스크립트로 글을 그리는 사이트, 로그인해야 보이는 글은 잘 안 됩니다.

## 주일 성경 본문에 묵상 쓰기: bib

```
bib
```

이번 주일(일요일)의 **개정 공동 성서정과**(Revised Common Lectionary) 본문을 엽니다.
주일 이름과 본문 목록은 밴더빌트 대학의 성서정과 달력(lectionary.library.vanderbilt.edu)에서,
본문은 Bible Gateway 에서 가져옵니다. 맨 위에 그 주일의 이름이 나옵니다
(예: "2026-11-22 Reign of Christ - Proper 29 (34)", 그 아래 "Twenty-Sixth Sunday after Pentecost").

본문 줄 사이에 바로 묵상을 쓰면 됩니다. `~/bible/2026-11-22.wg` 와 `.odt` 로 저장되고,
같은 날을 다시 부르면 쓰던 그대로 열립니다.

| 명령 | 하는 날 |
|---|---|
| `bib` | 이번 주일 (오늘이 주일이면 오늘) |
| `bib +1` / `bib -1` | 다음 주일 / 지난 주일 |
| `bib 2027-01-05` | 그 날짜의 주일 (그 날이 주일이 아니면 다음 주일) |

설정은 `~/.config/han/bible` 파일에 씁니다: 번역 `VERSION=ESV` (기본 NIV),
성령강림절 뒤의 구약 본문 `TRACK=semicontinuous` (기본 complementary, 주제에 맞춘 본문).

## 오늘 읽을 말씀: bibt

```
bibt
```

"일년 일독" 읽기표(1517.org 의 Bible in One Year: 날마다 구약 한 부분과 신약 한 부분)에서
**오늘 본문**을 찾아, 고른 번역으로 엽니다. 같은 날 다시 열면 읽던 곳부터 이어집니다.

## 성경 읽기: bibr

```
bibr
```

처음에는 책과 장을 고르고, 그다음부터는 **읽던 장, 읽던 곳**부터 열립니다 (전자책처럼).
장은 여러 개도 됩니다: `1-4` (1장부터 4장), `3-4,6` (3, 4, 6장). 한 문서로 이어서 열립니다.
바로 열기: `bibr 요한복음 3`, `bibr john 3-4`. 다시 고르기: `bibr -c`.

## bibt, bibr 의 번역과 키

`bibt` 는 ESV 로 엽니다. 1517 읽기표가 연결해 둔 바로 그 본문(1517.org)입니다. `c` 로 다른 영어 번역.
`bibr` 는 처음 한 번 번역을 묻습니다 (ESV, NIV, KJV, NRSVUE 등 영어 번역, Bible Gateway. Enter 는 ESV).
한국어 번역(개역개정, 개역한글, 표준새번역, 새번역, 공동번역, 공동번역 개정판, 대한성서공회)은 쓰고 싶을 때만:
번역 고르는 화면에서 `k` 를 누르면 목록에 나옵니다 (다시 `k` 는 숨기기).

| 키 | bibt | bibr |
|---|---|---|
| `Space`, `b` | 다음 쪽, 앞 쪽 | 다음 쪽, 앞 쪽 |
| `>` / `<` | 다음 날 / 앞 날 (장을 골랐으면 다음 장 / 앞 장) | 다음 장 / 앞 장 (다음 책으로 이어짐) |
| `a` | 읽기표의 절만 / 장 전체 바꾸기 | |
| `c` | 오늘 본문의 책에서 장 고르기 (`1-4,5` 처럼) | 번역, 책, 장 고르기 |
| `v` | 다른 영어 번역 | |
| `d` | 고른 장에서 오늘 말씀으로 돌아가기 | |
| `Alt+W` | WordGrinder 로 묵상 쓰기 | WordGrinder 로 묵상 쓰기 |
| `q` | 끝내기 (읽던 곳 기억) | 끝내기 (읽던 곳 기억) |

`Alt+W` 로 쓴 글은 저장(`Ctrl+S`)하면 읽던 화면에도 바로 보입니다. `F11` 의 옆 책도 같은 본문, 같은 곳을 보여 줍니다.
하루치는 `~/bible/daily/`, 장은 `~/bible/read/` 에 `.wg` (쓰기) 와 `.odt` (LibreOffice) 로 남습니다.
(한국어 본문은 대한성서공회 사이트가 장 단위라서 언제나 장 전체입니다.)

`hb` 로 읽는 다른 책에서도 `Alt+W` 를 누르면 그 책의 글이 새 WordGrinder 문서(`~/web/`)로 열립니다.

## 영어 단어 뜻: Alt+D

읽거나 쓰다가 모르는 영어 단어가 나오면 `Alt+D` 를 누르고, 그 단어의 앞 글자 몇 개를 입력합니다.
화면에서 그렇게 시작하는 단어들이 표시되고, 첫째 것에 커서가 갑니다. 다른 것이면 `Tab` 으로 옮기고,
`Enter` 를 누르면 오른쪽에 뜻이 나옵니다 (WordNet 영영사전). 화면에 없는 단어는 끝까지 입력하고 `Enter`.
`Esc` 는 입력 지우기, 뜻 닫기, 끝내기 순서입니다.

WordNet 에는 명사, 동사, 형용사, 부사만 있습니다. `the`, `of`, `and`, `he` 같은 짧은 기능어는 없습니다. `went`, `mice`, `tried` 처럼 바뀐 꼴도 원래 단어를 찾아 줍니다.
`q` 나 `Enter` 로 닫습니다. 명령으로는 `dic 단어`.

WordGrinder, `hb` 로 읽는 책, w3m 웹 페이지 등 데스크톱 화면의 글이면 어디서나 됩니다.
(`hv` 로 PDF 를 그림으로 볼 때는 안 됩니다. 글이 있는 PDF 는 `hb` 로 여세요.)

# AI 에게 묻기: gem

글을 쓰다가 막히면 옆에 AI 를 불러 물어볼 수 있습니다. 인터넷이 연결되어 있어야 합니다.

## 처음 한 번: 무료 키 넣기

1. 휴대폰이나 다른 컴퓨터에서 https://console.groq.com/keys 를 엽니다 (Google 계정으로 로그인).
2. **Create API Key** 를 눌러 키를 만듭니다. `gsk_` 로 시작하는 긴 글자입니다.
3. 다시 리눅스에서 `gem -k` 를 입력하고 키를 넣습니다.

(Google Gemini 키도 넣어 두면, Groq 가 안 될 때 대신 씁니다.)

## 쓰기

데스크톱에서 `Alt+G` 를 누르면 오른쪽에 **AI** 칸이 열립니다. 물어볼 것을 쓰고 `Enter`.
`Alt+G` 를 다시 누르면 닫힙니다. 대화는 남아서 다음에 이어집니다.

| 키, 명령 | 하는 일 |
|---|---|
| `Alt+G` | 열기 / 닫기 |
| `Alt+O` | 쓰던 글과 AI 칸 사이를 오가기 |
| `/new` | 새 대화 |
| `/copy` | 마지막 답 전체 복사 (붙여넣기는 F7) |
| `/pdf 이름 쪽` | PDF 한 쪽을 같이 보내기 (예: `/pdf 계약 3`). 이름은 일부만, 정규식도 됩니다 |
| `F12` 또는 `/help` | 쓰는 법 요약 |

## 답의 한 문장을 글로 가져가기

1. AI 칸에서 `F6` (화면이 멈춥니다)
2. 화살표로 문장의 첫 글자로 가서 `Space`
3. 화살표로 문장 끝까지 가서 `Enter`
4. `Alt+O` 로 WordGrinder 쪽으로 가서 `F7`

반대로 WordGrinder 의 글을 AI 에게 보낼 때도 같습니다: WordGrinder 에서 1-3, `Alt+O` 로 AI 칸에 와서 `F7`, 물어볼 말을 덧붙여 `Enter`.

> AI 의 답은 틀릴 수 있습니다. 중요한 내용은 확인하세요.

# 텍스트 편집: nano


화면 아래 두 줄에 지금 쓸 수 있는 키가 늘 나옵니다. `^` 는 Ctrl, `M-` 는 Alt 입니다.

여러 줄을 옮기려면 줄마다 `Ctrl+K` 를 누른 뒤, 옮길 곳에서 `Ctrl+U` 를 한 번 누릅니다.

# 유튜브: yt

Firefox 없이도, 오래된 노트북에서 유튜브를 볼 수 있습니다. 인터넷에 연결하고:

```
yt 아이유
```

(`F1` → **인터넷** → **유튜브** 로 열어도 됩니다.)

찾은 영상이 번호, 길이와 함께 나옵니다.

```
  1)     3:45  ...
  2)  1:02:03  ...
번호 = 영상, 번호s = 소리만 (예: 3s), 다른 말 = 새로 찾기, q = 끝
>
```

| 입력 | 하는 일 |
|---|---|
| `3` | 3번 영상을 화면 가득 봅니다 (가벼운 360p 화질) |
| `3s` | 3번을 **소리만** 듣습니다 (음악, 강의). 노트북이 아주 느릴 때도 됩니다 |
| 다른 말 | 새로 찾기 |
| `q` | 끝내기 |

보는 동안 키는 mpv 와 같습니다: `Space` 멈춤, `←`/`→` 5초, `9`/`0` 소리, `q` 끝.
`s` 는 빠르게: 누를 때마다 1.1, 1.25, 1.35, 1.45, 1.65, 1.8 배, 한 번 더 누르면 보통 속도 (느리게는 없습니다).
한글 입력이 켜져 있어도 `q`, `v`, `s` 가 됩니다 (목록에서는 `ㅂ`, `3ㄴ` 도 됩니다).
영상을 보는 동안은 입력이 **EN** 으로 바뀌었다가, 영상이 끝나면 다시 **한** 으로 돌아옵니다.
영상이 끝나면 목록으로 돌아옵니다.

영상을 틀어 둔 채 다른 일을 하려면 `Tab` 을 누르세요. 데스크톱으로 돌아가고, 영상과 소리는 계속됩니다.
`F4` 로 새 창을 열어 글을 쓰다가, `Alt+V` 를 누르면 다시 영상 화면으로 갑니다.

유튜브가 "로봇이 아닌지 확인(not a bot)" 하라며 막으면, 영상 탓이 아니라 인터넷 주소 탓입니다.
VPN 을 쓰고 있으면 끄고, 아니면 얼마 뒤 다시 해 보세요.

유튜브가 바뀌어 갑자기 안 되면, 인터넷에 연결된 상태에서 `had yt` 로 yt-dlp 를 새로 받습니다.

# 놀이: 도스 게임과 어드벤처

## 도스 게임: hdos

처음 한 번 도스박스를 설치합니다 (root, 인터넷 없이 됩니다): `had dosbox`.
도스박스가 열리지 않으면 `hdos` 가 까닭을 보여 줍니다. "EGL" 이 나오면 그래픽 칩의 드라이버가 없는 것입니다.

1. `~/dos` 폴더를 만들고 게임을 넣습니다. (USB 에서 복사: [USB 메모리 쓰기](#usb-메모리-쓰기))
2. `F1` → **놀이** → **도스 게임**, 또는:

   ```
   hdos
   ```

   도스 화면이 열리고 `~/dos` 가 `C:` 드라이브가 됩니다. 옛날처럼 `cd 게임폴더`, `게임.EXE`.
3. 게임을 바로 시작할 수도 있습니다.

   ```
   hdos ~/dos/게임/GAME.EXE
   ```

| 키 | 하는 일 |
|---|---|
| `Ctrl+F10` | 마우스 풀기 |
| `Ctrl+F9` | 도스 끝내기 |
| `Alt+Enter` | 창 / 전체 화면 |

게임이 너무 빠르거나 느리면 `/etc/han/dosbox.conf` 의 `cpu_cycles` 값을 바꿉니다.
옛날 한글 도스 프로그램은 도스 안에서 한글 상주 프로그램(한글 TSR)을 먼저 실행해야 할 수 있습니다.

|---|---|
| 전원 단추를 짧게 | 깔끔하게 끄기 (`poweroff` 와 같음) |
| 덮개 닫기 | 배터리로 쓰고 있으면 잠자기, 전원선이 꽂혀 있으면 그대로 |

오래된 노트북은 잠자기에서 잘 깨어나지 못하기도 합니다.
가방에 오래 넣어 둘 때는 `poweroff` 로 끄는 것이 안전합니다.

# 문제 해결

### 64비트 USB 가 켜지지 않고 영어 글이 나오고 멈춰요

32비트 노트북입니다. 32비트 ISO(`aneuu-0-x86.iso`)로 USB 를 다시 만드세요.

### USB 로 켜지지 않고 윈도우가 켜져요

부트 메뉴 키를 다시 확인하고, 시큐어 부트를 끄세요. ([USB 로 켜기](#usb-로-켜기))
USB 를 Rufus 로 만들었다면 **DD 이미지 모드**로 다시 만들어 보세요.

### 한글이 네모(□)나 물음표로 보여요

`desk` 안에서 쓰세요. 그래도 그렇다면 `han -f` 로 시작해 보세요.

### 한글이 안 쳐져요

오른쪽 Alt(또는 한/영 키)를 한 번 누르세요. 로그인한 바로 그 화면에서는 한글 입력이 안 됩니다. `desk` 를 먼저 켜세요.

### 무선랜 카드가 없다고 나와요 (No Wi-Fi card found)

리눅스가 모르는 무선랜 카드입니다. 랜선을 쓰거나, USB 무선랜(동글)을 꽂아 보세요.
어떤 카드인지는 `lspci` 로 볼 수 있습니다. 그 이름으로 찾아보면 도움이 됩니다.

### 무선랜 비밀번호가 맞는데 연결이 안 돼요

`r` 로 다시 찾은 뒤 한 번 더 해 보세요. 공유기와 너무 멀면 신호(dBm)가 -80 보다 작게 나옵니다.

### NetSurf, mpv, 도스 게임이 화면에 안 나와요

그래픽 칩이 너무 오래되었을 수 있습니다. 웹은 w3m 이나 chawan 을 쓰세요.

### 화면이 멈춘 것 같아요

| 해 볼 것 | 뜻 |
|---|---|
| `q` 또는 `Esc` | 대부분의 프로그램 닫기 |
| `Ctrl+C` | 지금 돌고 있는 명령 멈추기 |
| `Ctrl+Alt+F2` | 다른 콘솔로 가서 root 로 로그인 (돌아올 때 `Ctrl+Alt+F1`) |
| `reboot` | 다시 켜기 |

### USB 메모리의 한글 파일 이름이 깨져요

`mount` 대신 `husb` 로 연결하세요.

### 파일과 설정이 다 없어졌어요

USB 로 켜서 쓰면 끌 때 사라집니다. 파일은 다른 USB 에 복사해 두거나, 하드디스크에 설치하세요. ([저장과 설치](#저장과-설치))

### 소리가 안 나요

`alsamixer` 에서 `M` 으로 음소거를 풀고 소리를 키우세요.
블루투스 헤드폰을 쓰다가 끊었다면 음악이나 영상을 다시 틀어 보세요.

### 블루투스 기기가 목록에 안 나와요

기기를 다시 연결 대기(페어링) 상태로 두고, 노트북 가까이 가져온 뒤 `s` 로 다시 찾으세요.
다른 휴대폰에 이미 연결되어 있으면 그쪽 블루투스를 먼저 끄세요.

### 시각이 9시간 틀려요

인터넷에 연결하면 몇 초 안에 맞춰집니다. 그래도 틀리면 `setup-timezone` 에서 `Asia/Seoul` 을 고르세요.

# 부록 3: 낱말 풀이

콘솔
:   글자만 나오는 검은 화면. 다시 리눅스는 이 화면에서 씁니다.

셸, 프롬프트
:   명령을 입력받는 프로그램, 그리고 그 입력 자리(`aneuu:~#`).

root
:   컴퓨터의 관리자. 무엇이든 할 수 있으니 비밀번호를 꼭 정하세요.

부팅
:   컴퓨터가 켜지면서 운영체제를 불러오는 과정.

ISO 파일
:   CD 한 장을 통째로 담은 파일. 부팅 USB 를 만들 때 씁니다.

라이브(live)
:   설치하지 않고 USB 에서 바로 켜서 쓰는 방식. 끄면 바뀐 것이 사라집니다.

마운트(연결)
:   USB 같은 저장 장치를 폴더처럼 열어 쓰게 하는 일. 다시 리눅스에서는 `husb`.

패키지
:   설치할 수 있는 프로그램 묶음. `apk` 로 받고 지웁니다.

알파인 리눅스(Alpine Linux)
:   다시 리눅스의 바탕이 된 작고 가벼운 리눅스.
